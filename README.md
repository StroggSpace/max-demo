# max-demo

Сборник демо-экранов мини-приложения MAX: моки, автопроигрывание сценариев,
Lottie-анимации и тосты. Нужен для презентации фич бизнесу, без бэкенда и реальных данных.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5199
npm run build
npm run typecheck
```

## Что внутри

| Раздел | Что показывает |
|---|---|
| Главная | Баланс, уровень, прогресс, активный розыгрыш, живая лента |
| Задания | Выполнение заданий, прогресс, награды |
| Розыгрыши | Таймер, участники, участие, результат, конфетти |
| Магазин | Награды за баллы, обмен, инвентарь |
| Профиль | ЛК, статистика, рефералка, достижения |

Темы: светлая и тёмная. Переключаются в шапке и в панели демо.

## Дизайн-система

Только MAX UI: `@maxhub/max-ui` для всех компонентов и токенов.

- `MaxUI` — провайдер темы (`colorScheme`)
- `Typography`, `Panel`, `CellList`, `CellSimple`, `CellHeader`, `Button`,
  `IconButton`, `Grid`, `Flex`, `Avatar`, `Switch`
- Цвета, фоны, радиусы — CSS-переменные MAX (`--background-surface-*`,
  `--text-*`, `--background-accent-*`, `--gradient-blue`)
- Иконки — `@heroicons/react`, инлайновых SVG в проекте нет

Своя вёрстка осталась только там, где у MAX UI нет компонента: hero-блок,
прогресс-бар, таймер, конфетти-слой. Стилизуется теми же токенами.

## Сценарии

Каждый раздел при открытии проигрывает свой сценарий: заполняются прогрессы,
идут таймеры, появляются события и тосты. Сценарии лежат в `src/scenarios/`.

```ts
export const tasksScenario: Scenario = {
  id: 'tasks',
  title: 'Задания',
  reset: () => useDemoStore.getState().resetTasks(),
  steps: [
    { at: 700, run: () => useDemoStore.getState().completeTask(0) },
  ],
};
```

- Время шагов — демо-миллисекунды от старта. Скорость ×1/×2/×4 ускоряет всё разом.
- Сценарий пишет только через экшены стора, поэтому повторяем с чистого листа.
- Пользователь тронул экран, вкладка скрыта или включён `prefers-reduced-motion` —
  сценарий уступает управление.

### Как выключить

1. Глобально: панель демо → «Автопроигрывание», либо `?autoplay=0`.
2. По разделу: панель демо → «Сценарии по разделам».
3. На месте: панель управления сценарием над таббаром (пауза/заново/скорость).

## Тосты

`src/shared/ui/toast` — стек тостов на токенах MAX.

```ts
toast.success('Задание выполнено', '+50 баллов');
toast.reward('Вы выиграли!', 'Сертификат 1000 ₽');
toast.info('Заявка принята', 'Ожидайте результат');
```

Показываются из сценариев и из действий пользователя (участие, обмен, копирование кода).

## Lottie

`src/shared/ui/Lottie.tsx` — обёртка над `@lottiefiles/dotlottie-react`, формат `.lottie`.

| Файл | Где |
|---|---|
| `public/lottie/confetti.lottie` | финал розыгрыша |
| `public/lottie/coins.lottie` | баланс на главной и в магазине |

WASM-плеер лежит локально (`public/lottie/dotlottie-player.wasm`), поэтому
анимации работают офлайн и внутри MAX, без CDN. При `prefers-reduced-motion`
анимация не запускается.

## Структура

```
src/
  app/        провайдеры, роутер, ui-стор
  pages/      пять разделов
  widgets/    шапка, таббар
  features/   сценарии, розыгрыш, панель демо
  shared/     Lottie, тосты, ErrorBoundary
  platform/   адаптер MAX Bridge / браузер
  scenarios/  сценарии по разделам
  store/      стор демо-данных
  styles/     базовые стили на токенах MAX
```

## Платформа

`src/platform` подставляет пользователя и хаптику. В браузере — мок, внутри MAX —
`window.WebApp` (initData, HapticFeedback). Для публикации в MAX достаточно подключить
`max-web-app.js` и указать HTTPS-URL мини-приложения.

## Правила демо

- Только моки, никаких сетевых вызовов.
- Ничего из Telegram и крипты: ни `@username`, ни Stars, ни TON.
- Деньги — только баллы и партнёрские награды.
- Состояния обязательны: загрузка, пусто, ошибка, успех.
