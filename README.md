# max-demo

Демо мини-приложений MAX: категории бизнес-фич, автопроигрывание сценариев,
Lottie-анимации и интерфейсные анимации на `motion`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5199
npm run build
npm run typecheck
```

## Архитектура

Экран выбора категории → категория → вкладки внутри категории.

```
/                                  выбор категории
/category/:id                      категория (свой хедер и таббар)
/category/retention/season         вкладки блока «Удержание / геймификация»
/category/retention/tasks
/category/retention/achievements
/category/retention/profile
/settings                          глобальные настройки
```

- **Хедер** — назад, название категории, шестерёнка настроек.
- **Таббар** — свой у каждой категории, прокручивается по горизонтали.
- **Бизнес-фичи разделены**: блоки не смешиваются в одном экране.
- Работают все три категории: «Удержание / геймификация», «Продажи», «Сервис / коммуникация».
- Вкладки категорий подключаются через реестр `src/app/categoryTabs.ts`.

## Блок «Удержание / геймификация»

| Вкладка | Что показывает |
|---|---|
| Сезон | Прогресс сезона, 5 уровней и награды (розыгрыши, кэшбэк, промокоды, статус) |
| Задания | Общий прогресс, задания, брейкпоинты и промокоды |
| Достижения | 5 достижений, открываются в процессе |
| Профиль | Статистика и история действий (только события пользователя) |

### Промокоды

Четыре брейкпоинта — по числу выполненных заданий. На каждом открывается свой
промокод: модалка с описанием, кодом и кнопкой копирования, конфетти на фоне.

Сценарий заданий последовательный: задание → модалка промокода → закрытие
(автоматически через 2 секунды или вручную) → следующее задание. Если закрыть
модалку раньше, следующее задание запускается сразу.

```
1 задание  → START10   скидка 10%
2 задания  → BONUS500  500 баллов
3 задания  → FREESHIP  бесплатная доставка
4 задания  → VIP15     скидка 15% и статус
```

### Сезон

5 уровней: Новичок → Участник (розыгрыши) → Активный (кэшбэк 5%) →
Привилегированный (промокод 500 ₽) → Амбассадор (скидка 15% и статус).

## Блок «Продажи»

| Вкладка | Что показывает |
|---|---|
| Витрина | Каталог товаров, цены в рублях и баллах, добавление в корзину |
| Корзина | Отдельная панель: позиции, количество, промокод, итог, оформление заявки. Бейдж с количеством товаров |
| Розыгрыши | Приз, таймер, участники, участие, результат, конфетти |
| Рефералка | Код, шеринг, приглашённые, прогресс до бонуса |

- Оплаты нет: оформляется заявка, показывается номер и сумма.
- Промокод `START10` даёт −10% в корзине.
- Цены в рублях, рядом — сколько это в баллах.
- «Поделиться» использует `shareContent` в MAX и `navigator.share`/буфер в браузере.

## Блок «Сервис / коммуникация»

| Вкладка | Что показывает |
|---|---|
| Заявки | Статусы обращений, прогресс «принята → в работе → готова», документы |
| Запись | 8 услуг и 5 мастеров: услуга фильтрует мастеров, мастер — свободные слоты; сводка и подтверждение |
| Чат-бот | Диалог с ботом, быстрые ответы, индикатор «печатает» |
| Карта | QR-карта лояльности, баланс, срок действия, обновление кода |

- Запись зависимая: смена услуги сбрасывает неподходящего мастера и время, смена мастера — время.
- QR настоящий, через `qrcode.react`, лежит на белой подложке для сканируемости.
- Код карты обновляется автоматически по сценарию и по кнопке.
- Быстрые ответы бота можно нажимать: приходит ответ с задержкой и индикатором набора.

## Сценарии

При входе во вкладку сценарий проигрывается автоматически: задания выполняются,
уровни растут, достижения открываются, промокоды всплывают модалкой.

- Включается/выключается в настройках (`Автопроигрывание`).
- Шаги живут в миллисекундах от старта, выполняются через `requestAnimationFrame`.
- Каждая вкладка при входе сбрасывает свои данные и играет заново.
- В режиме «Состояние интерфейса» (загрузка/пусто/ошибка) сценарии не запускаются.

## Уведомления

Тостов в проекте нет. Обратная связь — модалка промокода, конфетти и инлайн-счётчики.

## Дизайн и анимации

- MAX UI: `Typography`, `Panel`, `CellSimple`, `Button`, `IconButton`, `Grid`,
  `Flex`, `Avatar`, `Switch`, `Spinner`
- токены MAX: `--background-surface-*`, `--text-*`, `--background-accent-*`,
  `--spacing-size-*`, `--size-border-radius-*`
- иконки `@heroicons/react`, инлайновых SVG нет
- Lottie `.lottie`, WASM-плеер локально (`public/lottie`)

### Типографика

Единый слой токенов — `src/styles/typography.css`:

- размеры: `--font-size-3xs … --font-size-6xl`
- насыщенность: `--font-weight-regular … --font-weight-extrabold`
- интерлиньяж: `--line-height-none … --line-height-relaxed`
- трекинг: `--letter-spacing-tight … --letter-spacing-code`

Семантические классы для новых категорий: `.type-display`, `.type-title`,
`.type-stat`, `.type-code`, `.type-tab`, `.type-overline`.

Правило: в CSS-модулях и компонентах нет литеральных `font-size`, `font-weight`,
`line-height`, `letter-spacing` — только переменные.

### Motion

Все анимации описаны в одном месте — `src/shared/motion/config.ts`:
переходы страниц, появление карточек, модалка, поп-апы, тап-состояния.
Компоненты берут пресеты через `useMotionControls()`.

- включение/выключение — в настройках, флаг хранится в localStorage;
- при выключении пресеты становятся мгновенными (`duration: 0`);
- переходы страниц работают в обе стороны через `AnimatePresence`:
  старый экран уезжает, новый появляется;
- CSS-анимаций и transition в проекте нет — только motion.

Кнопка «Назад» в хедере всегда возвращает на выбор категорий.

## Лэйаут

```

  AppHeader  flex: 0 0 auto
  .main      flex: 1, overflow-y: auto
  TabBar     flex: 0 0 auto
```

Контент внутри — колонка до 640px. Скроллится только `main`.

## Настройки

`/settings`, вход через шестерёнку в хедере.

- тема: светлая / тёмная
- автопроигрывание
- состояние: обычное / загрузка (скелетоны) / пусто / ошибка
- сброс данных демо
