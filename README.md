# max-demo

Демо мини-приложений MAX: категории бизнес-фич, автопроигрывание сценариев,
Lottie-анимации и интерфейсные анимации на `motion`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5199
npm run build
npm run typecheck
```

## Архитектура

Экран выбора категории → категория → вкладки внутри категории.

```
/                                  выбор категории
/category/:id                      категория (свой хедер и таббар)
/category/retention/season         вкладки блока «Удержание / геймификация»
/category/retention/tasks
/category/retention/achievements
/category/retention/profile
/settings                          глобальные настройки
```

- **Хедер** — назад, название категории, шестерёнка настроек.
- **Таббар** — свой у каждой категории, прокручивается по горизонтали.
- **Бизнес-фичи разделены**: блоки не смешиваются в одном экране.
- Сейчас работает «Удержание / геймификация», «Продажи» и «Сервис / коммуникация» — заглушки.

## Блок «Удержание / геймификация»

| Вкладка | Что показывает |
|---|---|
| Сезон | Прогресс сезона, 5 уровней и награды (розыгрыши, кэшбэк, промокоды, статус) |
| Задания | Общий прогресс, задания, брейкпоинты и промокоды |
| Достижения | 5 достижений, открываются в процессе |
| Профиль | Статистика и история действий (только события пользователя) |

### Промокоды

Четыре брейкпоинта — по числу выполненных заданий. На каждом открывается свой
промокод: модалка с описанием, кодом и кнопкой копирования, конфетти на фоне.

Сценарий заданий последовательный: задание → модалка промокода → закрытие
(автоматически через 2 секунды или вручную) → следующее задание. Если закрыть
модалку раньше, следующее задание запускается сразу.

```
1 задание  → START10   скидка 10%
2 задания  → BONUS500  500 баллов
3 задания  → FREESHIP  бесплатная доставка
4 задания  → VIP15     скидка 15% и статус
```

### Сезон

5 уровней: Новичок → Участник (розыгрыши) → Активный (кэшбэк 5%) →
Привилегированный (промокод 500 ₽) → Амбассадор (скидка 15% и статус).

## Сценарии

При входе во вкладку сценарий проигрывается автоматически: задания выполняются,
уровни растут, достижения открываются, промокоды всплывают модалкой.

- Включается/выключается в настройках (`Автопроигрывание`).
- Шаги живут в миллисекундах от старта, выполняются через `requestAnimationFrame`.
- Каждая вкладка при входе сбрасывает свои данные и играет заново.
- В режиме «Состояние интерфейса» (загрузка/пусто/ошибка) сценарии не запускаются.

## Уведомления

Тостов в проекте нет. Обратная связь — модалка промокода, конфетти и инлайн-счётчики.

## Дизайн и анимации

- MAX UI: `Typography`, `Panel`, `CellSimple`, `Button`, `IconButton`, `Grid`,
  `Flex`, `Avatar`, `Switch`, `Spinner`
- токены MAX: `--background-surface-*`, `--text-*`, `--background-accent-*`,
  `--spacing-size-*`, `--size-border-radius-*`
- `motion` (`motion/react`) — вход карточек категорий, тап-состояния, модалка
- иконки `@heroicons/react`, инлайновых SVG нет
- Lottie `.lottie`, WASM-плеер локально (`public/lottie`)

## Лэйаут

```
.shell  max-width 1024px, height 100dvh, flex column
  AppHeader  flex: 0 0 auto
  .main      flex: 1, overflow-y: auto
  TabBar     flex: 0 0 auto
```

Контент внутри — колонка до 640px. Скроллится только `main`.

## Настройки

`/settings`, вход через шестерёнку в хедере.

- тема: светлая / тёмная
- автопроигрывание
- состояние: обычное / загрузка (скелетоны) / пусто / ошибка
- сброс данных демо

## Структура

```
src/
  app/        провайдеры, роутер, shell, категории, достижения

  widgets/    хедер, таббар категории
  features/   движок сценариев
  shared/     kit-примитивы, Lottie, PromoModal, ErrorBoundary
  platform/   адаптер MAX Bridge / браузер
  scenarios/  сценарии вкладок
  store/      данные демо

```
