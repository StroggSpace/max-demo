# max-demo

Сборник демо-экранов мини-приложения MAX: моки, автопроигрывание сценариев,
Lottie-анимации и тосты. Нужен для презентации фич бизнесу, без бэкенда и реальных данных.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5199
npm run build
npm run typecheck
```

## Экраны

| Раздел | Что показывает |
|---|---|
| Главная | Баланс, уровень, прогресс, активный розыгрыш, живая лента |
| Задания | Выполнение заданий, прогресс, награды |
| Розыгрыши | Таймер, участники, участие, результат, конфетти |
| Магазин | Награды за баллы, обмен, инвентарь |
| Профиль | ЛК, статистика, рефералка, достижения |
| Настройки | Тема, скорость, автоплей, разделы, состояния |

## Лэйаут

Продакшен-схема без `position: fixed`: оболочка — flex-колонка на всю высоту.

```
.appRoot  → центрирует оболочку
.shell    → max-width 1024px, height 100dvh, flex column
  .main      flex: 1, overflow-y: auto
  TabBar     flex: 0 0 auto
```

Верхней шапки нет — контент начинается сразу, у страниц есть заголовок как часть контента.

- Оболочка тянется до 1024px, дальше не растёт.
- Контент внутри — колонка до 640px по центру, чтобы строки не расползались.
- Скроллится только `main`, шапка и таббар всегда на месте, без absolute/fixed.
- На экранах шире 560px оболочка получает отступ, рамку и скругление.

## Дизайн-система

Только MAX UI: `@maxhub/max-ui` для компонентов и токенов.

- `Typography`, `Panel`, `CellList`, `CellSimple`, `CellHeader`, `Button`,
  `IconButton`, `Grid`, `Flex`, `Avatar`, `Switch`
- Цвета, фоны, радиусы — переменные MAX (`--background-surface-*`, `--text-*`,
  `--background-accent-*`, `--gradient-blue`)
- Отступы — шкала `--spacing-size-*`, свои «на глаз» не используются
- Иконки — `@heroicons/react`, инлайновых SVG нет
- Стили — CSS-модули, инлайновый `style` остался только для динамики (ширина прогресса)

Общие примитивы лежат в `src/shared/ui/kit`: `Card`, `ListCard`, `Section`, `Hero`,
`Progress`, `Balance`, `Stat`, `Chip`, состояния (`StateGate`).

## Настройки

Отдельная страница `/settings`, вход через шестерёнку в профиле.

- тема: светлая / тёмная
- автопроигрывание
- показ состояний: обычное / загрузка (скелетоны) / пусто / ошибка
- сброс данных демо

## Сценарии

Сценарий запускается при входе в раздел, если автоплей включён, раздел не отключён
и не выбран режим состояния. Плеера и паузы на экране нет: либо автоплей, либо
ручное управление интерфейсом.

```ts
export const tasksScenario: Scenario = {
  id: 'tasks',
  title: 'Задания',
  reset: () => useDemoStore.getState().resetTasks(),
  steps: [{ at: 700, run: () => useDemoStore.getState().completeTask(0) }],
};
```

- Шаги живут в демо-времени, скорость применяется на лету.
- Сценарий пишет только через экшены стора, поэтому воспроизводим с чистого листа.

## Тосты

`src/shared/ui/toast` — показывается один тост, автоскрытие 2.6 с.

```ts
toast.success('Задание выполнено', '+50 баллов');
toast.reward('Вы выиграли!', 'Сертификат 1000 ₽');
toast.info('Заявка принята', 'Ожидайте результат');
```

## Lottie

`src/shared/ui/Lottie.tsx` — обёртка над `@lottiefiles/dotlottie-react`, формат `.lottie`.

| Файл | Где |
|---|---|
| `public/lottie/confetti.lottie` | финал розыгрыша |
| `public/lottie/coins.lottie` | баланс |

WASM-плеер лежит локально, анимации работают офлайн и внутри MAX.
