# max-demo

Сборник демо-экранов мини-приложения MAX: моки, автопроигрывание сценариев и Lottie.
Нужен для презентации фич бизнесу, без бэкенда и без реальных данных.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5199
npm run build
npm run typecheck
```

## Что внутри

| Раздел | Что показывает |
|---|---|
| Главная | Баланс, уровень, прогресс, активный розыгрыш, живая лента |
| Задания | Выполнение заданий, прогресс, награды |
| Розыгрыши | Таймер, участники, участие, результат |
| Магазин | Награды за баллы, обмен, инвентарь |
| Профиль | ЛК, статистика, рефералка, достижения |

Темы: светлая и тёмная, переключаются в шапке и в панели демо.

## Сценарии

Каждый раздел при открытии проигрывает свой сценарий: заполняются прогрессы,
идут таймеры, появляются события. Сценарии лежат в `src/scenarios/`.

```ts
export const tasksScenario: Scenario = {
  id: 'tasks',
  title: 'Задания',
  reset: () => useDemoStore.getState().resetTasks(),
  steps: [
    { at: 700, run: () => useDemoStore.getState().completeTask(0) },
  ],
};
```

- Время шагов — демо-миллисекунды от старта. Скорость ×1/×2/×4 ускоряет всё разом.
- Сценарий пишет только через экшены стора, поэтому повторяем с чистого листа.
- Пользователь тронул экран, вкладка скрыта или включён `prefers-reduced-motion` —
  сценарий уступает управление.

### Как выключить

1. Глобально: панель демо → «Автопроигрывание», либо `?autoplay=0`.
2. По разделу: панель демо → «Отключить сценарии» → нужный раздел.
3. На месте: панель управления сценарием над таббаром (пауза/заново/скорость).

## Структура

```
src/
  app/        провайдеры, роутер, ui-стор
  pages/      пять разделов
  widgets/    шапка, таббар
  features/   сценарии, розыгрыш, панель демо
  shared/     Lottie, ErrorBoundary, общие стили
  platform/   адаптер MAX Bridge / браузер
  scenarios/  сценарии по разделам
  store/      стор демо-данных
  styles/     токены и базовая вёрстка
```

## Платформа

`src/platform` подставляет пользователя и хаптику. В браузере — мок, внутри MAX —
`window.WebApp` (initData, HapticFeedback). При публикации в MAX-боте достаточно
подключить `max-web-app.js` и указать HTTPS-URL мини-приложения.

## Правила демо

- Только моки, никаких сетевых вызовов.
- Ничего из Telegram и крипты: ни `@username`, ни Stars, ни TON.
- Деньги — только баллы и партнёрские награды.
- Состояния обязательны: загрузка, пусто, ошибка, успех.

## Lottie

`src/shared/ui/Lottie.tsx` — обёртка над `@lottiefiles/dotlottie-react`.
Ассеты лежат в `public/lottie/`. При `prefers-reduced-motion` анимация не играет.
